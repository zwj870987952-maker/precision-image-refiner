# Precision Image Refiner

在用户指定区域改善商业图片的真实感，保持其余画面的构图、产品、品牌文字和光线。原图是构图基准；参考图默认只提供材质信息，用户另有明确要求时以用户要求为准。

## 理解编辑边界

先查看原图和参考图，确定允许修改的区域、需要保留的元素、参考图用途和交付尺寸。已有明确指令时直接执行；只有缺图、无法辨认待修区域或要求相互冲突时才提出必要问题，不重复索要确认。

- 默认保持主体数量、位置、比例、轮廓、朝向、遮挡与接触阴影。不把参考图的树枝、落花、物体或构图带入原图。
- 通过具体材质细节替换伪噪点：花瓣细微脉络与哑光表面、青苔成簇纤维、岩石孔隙与矿物切面、液体表面张力。避免只写“降噪”造成蜡感，也不自动添加露珠、光斑或锐化光晕。
- 产品标签、文字和标识需要逐一核对。生成模型无法保证像素级不变；严格保留应依靠工具支持的蒙版或用户授权的原图合成，不能仅凭提示词承诺。

## 在 Codex 中编辑图片

使用当前会话实际提供的图片编辑工具。优先调用原生 `image_gen` 的图片编辑能力，并遵循该工具及可用 imagegen skill 的输入、输出约定；不要照搬 Gemini 的 `generate_image` 调用。工具不可用时说明缺少编辑能力，不虚构结果。

- 本地图片先用 `view_image` 查看；所有目标图片都有本地路径时传入 `referenced_image_paths`。
- 有目标图片仅存在于聊天附件时，按工具约定使用 `num_last_images_to_include`，取能覆盖目标的最小数量；两种引用方式不要同时传。无法覆盖全部必要图片时请用户重新附图。
- 明确每张图的角色：原图为 `COMPOSITION MASTER`，参考图为 `TEXTURE REFERENCE ONLY`。只列出本图确实存在、用户要求保留或修改的元素。不要把模板的花朵数量、瓶身或暖色背景当作通用约束。
- 保留原图透明通道；用户明确要求去底或透明背景时设置透明背景选项。
- 原生工具结果通过其媒体输出方法展示。拿到真实可读的本地文件后才能运行后续脚本；不要把媒体 URL 或不存在的路径当成本地文件。

需要详细提示词时读取 [references/prompt_templates.md](references/prompt_templates.md)。其中花草、蜜液、岛屿底座只是示例，使用前按当前图片改写。

## 可选的本地神经超分

只有用户要求超分、4K/5K 导出、指定像素尺寸或本地超分管线时才执行。普通局部编辑无需自动生成所有大图，也不以 Python 脚本替代原生生成编辑能力。遵循当前会话对图片工具和脚本的限制。

内置脚本使用 RealESRGAN x4 ONNX、重叠分块和 Lab 色度回填。它不能恢复拍摄中不存在的真实细节，也不能保证零色差、无伪影或印刷认证。

执行前读取 [references/super_resolution.md](references/super_resolution.md)，检查依赖和本地模型。脚本默认只使用本地模型；缺少模型时明确说明，实际需要下载时使用显式下载选项。不要为安装技能预先下载模型或生成商业图片。

路径相对于本 skill 文件夹解析，而非当前项目。Windows PowerShell 示例：

```powershell
python "<skill目录>/scripts/master_superres_pipeline.py" --input "<原图绝对路径>" --output "<输出目录绝对路径>" --prefix product_master --model "<本地x4模型绝对路径>"
```

4K/5K 在本技能中表示长边 3840/5120 像素并保持比例。先做神经 x4，再重采样到导出尺寸；目标大于神经结果时应披露额外插值。300 DPI 是导出元数据，不是质量证明。背景平滑默认关闭，仅在有明确背景蒙版和相应需求时开启。

## 验收与交付

查看全图与待修区域的实际像素裁切，检查构图漂移、错字、重复纹理、拼缝、过锐和偏色。生成结果越过编辑范围时按用户要求修正，不把未验证的结果称为像素锁定或无损复原。

交付用户要求的文件、全图预览和相关细节裁切，并报告实际像素尺寸与剩余问题。PNG 为无损编码；JPEG 即使质量为 100 仍是有损编码。使用真实的绝对文件路径提供下载链接；本机文件不得宣称为公开网址。遵守工作区指定的输出目录约定。
